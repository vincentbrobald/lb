# Contributing

The repositories on [github.com/vincentbrobald](https://github.com/vincentbrobald)
are published copies: they are developed elsewhere, and every change there
replaces their whole content with a single "Sync" commit. A pull request on
GitHub therefore can't be merged as is.

- **Issues are welcome**: bugs, questions, ideas. Say which repository and,
  for a bug, what you ran and what you got.
- **Pull requests are welcome too, as proposals**: when one is accepted, the
  change is made in the source and comes back here with the next sync, and
  the pull request is closed with a link to it. The sync commits don't carry
  authors: you are credited in the pull request and in the issue it closes.
- **Security issues**: please don't open a public issue; use GitHub's
  private vulnerability reporting (the repository's Security tab).

By contributing you agree that your contribution is licensed under the
repository's license (LICENSE).
